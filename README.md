# Start virtual env

```
call "C:\py\TP Final\venv\Scripts\activate.bat"
```

## Guardar librerias instaladas
```
PS C:\py\TP Final> .\venv\Scripts\python.exe -m pip freeze > .\requirements.txt
```

## Instalar nuevas librerias
```
PS C:\py\TP Final> .\venv\Scripts\python.exe -m pip <nombre-libreria>
```
